## Summary

松浦茂樹による論説「見沼田んぼの成立と展開」（『野外調査研究』第1号（通巻第26号）2017年7月、pp.23-39）で、見沼低地が入江から沼・湿地、溜井、水田へと変遷した過程を、1629年の伊奈忠治による八丁堤築堤（第一次開発）と1727年着手の井澤為永による見沼代用水路開削（第二次開発）の二段階として整理する。あわせて戦後の乾田化・畑作転換にともなう野田のサギ山の消滅、狩野川台風を背景とする見沼三原則の制定、および見沼周辺の氷川三社と名神大社をめぐる著者自身の仮説を論じ、今後の保全・活用の方向を提言している。
