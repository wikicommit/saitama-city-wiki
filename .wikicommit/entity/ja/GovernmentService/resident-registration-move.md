住民異動届は、住所や家族構成などが変わったときにさいたま市へ届け出る住民登録の手続きである。届出の種類は、さいたま市に越してきた場合の転入届、市内で引っ越した場合の転居届、さいたま市から転出する場合の転出届、および世帯主変更・世帯合併・世帯分離の届出に分かれる。いずれも所定の期間内に届け出る必要がある。

届出の場所は各区役所区民課および各支所で、市役所（本庁）および市民の窓口では受け付けていない。転出届については窓口のほか、郵送とマイナポータルを通じたオンライン申請も利用できる。

3月中旬から4月中旬は各区区民課の窓口が大変混み合い、特に月曜日・金曜日・祝日明けの開庁日、休日窓口開設日、および10時頃から14時頃までが混雑すると案内されている。

## Eligibility & Scope

対象となるのはさいたま市に住所を有する人、または新たに住所を定める人で、届出は本人または世帯主のほか、その他の者も行える。代理人が届け出る場合は委任状が必要で、親族であっても世帯が別の場合は委任状を要する。外国人は在留カードまたは特別永住者証明書の持参が必要である。

| 届出の名称 | 届出期間 |
| --- | --- |
| 転入届 | 転入をした日から14日以内（外国人の場合、在留資格変更許可等を受けて新たに中長期在留者となった日から14日以内） |
| 転出届 | 転出する前に（1か月前から）受け付ける |
| 転居届 | 転居をした日から14日以内 |
| 世帯主変更届 | 変更があった日から14日以内 |
| 世帯分離届 | 変更があった日から14日以内 |
| 世帯合併届 | 変更があった日から14日以内 |

届出には本人確認書類と印鑑のほか、国民健康保険資格確認書等、後期高齢者医療資格確認書、介護保険被保険者証、国民年金手帳、子育て支援医療費受給資格証、印鑑登録証、個人番号カードなど、届出の種類と本人の加入状況に応じた書類が必要となる。転入届では前住所地の市区町村役場が発行した転出証明書が必要であり、海外からの転入の場合は戸籍謄本および[[DefinedTerm/koseki]]の附票（日本国籍で市外に本籍がある場合）、異動者全員分のパスポートなどが求められる。

建物を新築または改築し、引越し先が住居表示実施地区にあたる場合は、該当する区役所区民課で「建物その他の工作物新築届」（付定申請）を行う必要がある。この手続きが済んでいないと住所の表示が決まらず、転入・転居の手続きができない。また区画整理地では「底地」の地番が住所となるため、区画整理地の新築一戸建てへ異動する場合は底地番証明書および底地番証明図の持参が必要である。

## How to Use

窓口は各区役所区民課および各支所である。各区役所には手話通訳者が配置されている。平日に来庁できない場合は[[GovernmentService/ward-office-holiday-counter]]を利用できる。

### 来庁者の本人確認

本人の知らない間に転出入などの届出がなされる虚偽の届出事件が全国で発生していることを受け、来庁者には運転免許証、パスポート等の顔写真のある官公署発行の身分証明書の持参が求められている。本人確認ができなかった場合は、後日、届出があったことが郵送で連絡される。

### マイナポータルを通じたオンラインでの転出届

令和5年2月6日から、転出届についてマイナポータルを通じたオンラインでの届出が可能になった。利用できるのは電子証明書が有効なマイナンバーカードを持ち、日本国内で引越しをする人で、本人単身のほか同一世帯員や本人以外の世帯員の引越しでも利用できる。このサービスを利用すると転出にあたって区役所区民課などへの来庁が原則不要となるが、提出後は別途、転入先市区町村の窓口で転入届等の手続きが必要である。申請内容はすべて職員が確認したうえで処理するため、通常2〜3開庁日後に転出処理が完了する。土日祝日を挟む申請や3〜4月の繁忙期の申請では、通常よりも日数を要する場合がある。

マイナポータルで申請ができる期間は、新しい住所に住み始める30日前から、住み始めた日以後10日以内である。引っ越した日から11日以上経過している場合はマイナポータルから申請できないため、郵送で転出の届出を行うか、各区区民課・支所に来庁する必要がある。

利用にあたって必要なものは、電子証明書が有効なマイナンバーカードと、マイナンバーカードの読み込みに対応したスマートフォンまたはパソコンである。パソコンでの利用にはICカードリーダライタが必要で、スマホ用電子証明書を搭載したスマートフォンでも手続きできる。また、マイナンバーカードの署名用電子証明書の暗証番号（6〜16桁の英数字）、利用者用電子証明書の暗証番号（数字4桁）、券面事項入力補助用暗証番号（数字4桁）が必要となる。電子証明書が失効している場合はサービスを利用できない。

申請状況が更新されるとお知らせメールが届くため、マイナポータルにログインしてマイメニューの「申請状況照会」から確認する。マイナポータルでメールアドレスが未登録の場合や「通知を受け取る」のチェックを外している場合は、申請処理状況や利用者への連絡事項の登録・更新があってもお知らせメールが届かない。

なおマイナポータルを通じて転出届を提出した後は、転出予定者および同一世帯に転出予定者がいる世帯の人はコンビニエンスストアで各種証明書を取得できないため、区役所等の窓口で請求することになる。転入（さいたま市へ引っ越し）や転居（さいたま市内で引っ越し）は、マイナポータルでは手続きできず窓口での手続きが必要である。

マイナポータルのサービス利用方法に関する問合せは、マイナンバー総合フリーダイヤル（0120-95-0178）が受け付けている。受付時間は平日が9時30分から20時まで、土曜・日曜日および祝・休日が9時30分から17時30分まで（年末年始を除く）で、電話後の音声ガイダンスで「4番：マイナポータル及びスマホ用電子証明書に関するお問い合わせ」を指定する。このほか、マイナポータルにログイン後の「お問い合わせの登録」からWEBサイトによる問合せもできる。

### 郵送での転出届

窓口に届出できない場合は郵送で転出の届出ができる。この場合は必ず本人が届け出るものとされ、市が公開している「郵送による転出届」の様式に必要事項を記入・押印のうえ、切手を貼った返信用封筒と本人確認ができる書類の写しを添えて、住民登録のある区の区民課あてに送付する。

なお転出手続き後、転入の手続きが完了するまでの間、転出予定者および同一世帯の人については窓口と郵送でのみ証明書の請求を受け付けている。
